## data-testid markers

| Marker | Element |
|---|---|
| `participant-status` | status of a participant (one per participant); text = connection status |
| `participant-heartbeat` | last heartbeat of a participant (one per participant); text = time or age |
| `encryption-chart` | chart of the Paillier encryption times (`canvas`, `svg` or a container that holds them) |
| `replay-frame` | area showing the operation of the current frame |
| `replay-step` | "step forward by one frame" button |
| `replay-play` | button that starts the playback |
| `replay-pause` | button that pauses the playback |
| `replay-timeline` | timeline control (preferably `input type=range`, otherwise a clickable bar) |
| `replay-position` | indicator of the current position (e.g. "Frame 3/12") |
| `diff-changed` | row of a changed parameter (one per parameter), the element that carries the highlighting |
| `diff-before` | value before the change, inside `diff-changed` |
| `diff-after` | value after the change, inside `diff-changed` |

## Notes

- All data is simulated in the browser: no data server and no real encryption.
- The status or the last heartbeat of the participants updates by itself at least every 5 seconds.
- At least 2 participants; each participant has its own `participant-status` and `participant-heartbeat`.
- The differences view is visible on load with at least one example change (not only after reaching a frame).
- `diff-changed` goes on the element that carries the highlighting (colour, background or border), with
  `diff-before` and `diff-after` inside it.
- `replay-play` and `replay-pause` are two distinct elements; `replay-pause` may appear only during playback.
- On load the current frame is not the last one, and playback advances by at least one frame within 5 seconds.
