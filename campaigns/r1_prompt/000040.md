## Routes contract

Prefix `/api`, request and response bodies in JSON. Prices are numbers.

| Method | Path | Request body | Response | Errors |
|---|---|---|---|---|
| GET | `/api/catalog` | — | `200` `[{"id": str, "type": "service"\|"workshop"\|"class", "title": str, "price": number}]` (at least 1 `service` and 1 `workshop`) | — |
| GET | `/api/cart` | — | `200` `{"items": [{"id": str, "itemId": str, "quantity": int}]}` | — |
| POST | `/api/cart` | `{"itemId": str, "quantity": int}` (`quantity` optional, default 1) | `201` `{"id": str, "itemId": str, "quantity": int}` | `400` if `itemId` is missing or not in the catalogue, or `quantity` is not an integer >= 1 |
| PATCH | `/api/cart/{id}` | `{"quantity": int}` | `200` the updated item | `400` `quantity` not an integer >= 1; `404` unknown id |
| DELETE | `/api/cart/{id}` | — | `204` | `404` unknown id |
| POST | `/api/orders` | `{"card": str}` | `201` `{"id": str, "items": [{"itemId": str, "quantity": int}], "total": number}`; after the order the cart is empty | `400` if `card` is missing or empty, or the cart is empty |
| GET | `/api/orders/{id}` | — | `200` the order as above | `404` unknown id |

**Persistence:** cart and orders in a JSON file (`data/store.json`) or SQLite (`data/app.db`) in the workspace; they
survive a restart of `start.sh`. The catalogue may be static in the code.

## data-testid markers

| Marker | Element |
|---|---|
| `nav-link-<section>` | link of the navigation bar, one per section: `nav-link-home`, `nav-link-services`, `nav-link-workshops`, `nav-link-classes`, `nav-link-podcasts`, `nav-link-blogs`, `nav-link-contact`, `nav-link-cart` |
| `site-nav` | the navigation bar (container of the `nav-link-<section>` links) |
| `service-item` | card of a purchasable service (contains its `add-to-cart`) |
| `add-to-cart` | "add to cart" button on every purchasable item |
| `workshop-item` | card of a workshop (date, topic, speaker and its `add-to-cart`) |
| `class-item` | card of an online class |
| `podcast-item` | a podcast episode |
| `blog-post` | an article (or article preview) on the Blog page |
| `cart-item` | a row of the cart |
| `checkout-card` | text field for the card number |
| `checkout-submit` | button that confirms the purchase |
| `order-confirmation` | confirmation message after a successful purchase |

## Notes

- Payment is simulated: no real gateway and no card validation beyond "not empty".
