## Routes contract

All responses are JSON. Dates are ISO 8601 strings (`YYYY-MM-DD` or `YYYY-MM-DDTHH:MM`).

| Method | Path | Request body | Response | Errors |
|---|---|---|---|---|
| GET | `/api/cars` | — | 200: `[{id, name, type, price_per_day}]`, at least 2 items, `price_per_day` a number > 0 | — |
| GET | `/api/cars/:id/availability?start=…&end=…` | — | 200: `{available: true\|false}` | 400 missing or malformed dates, or `end` <= `start`; 404 unknown car |
| GET | `/api/payment-methods` | — | 200: `[string]`, at least 2 items | — |
| POST | `/api/bookings` | `{car_id, start_date, end_date, payment_method}` | 201: `{id, reference, car_id, start_date, end_date, payment_method, total_price, status}` with `status` = `"confirmed"` and `reference` a non-empty, unique string | 400 missing or malformed field, `end_date` <= `start_date`, `payment_method` not in `/api/payment-methods`; 404 unknown `car_id`; 409 overlap with an active booking of the same car |
| GET | `/api/bookings` | — | 200: list of bookings (same shape as the 201) | — |
| GET | `/api/bookings/:id` | — | 200: the booking | 404 |
| PATCH | `/api/bookings/:id` | subset of `{start_date, end_date, payment_method, status}`; `status` only accepts `"cancelled"` | 200: updated booking, `total_price` recomputed | 400 as for POST, or invalid `status`; 404; 409 overlap |
| DELETE | `/api/bookings/:id` | — | 204 | 404 |

A booking with `status` = `"cancelled"` no longer blocks availability.

**Persistence:** a file `data/db.json` **or** an SQLite database `data/app.sqlite` in the root of the workspace. The
data must survive a restart of `start.sh`.

## data-testid markers

| Marker | Element |
|---|---|
| `car-card` | each car of the catalogue (repeated); clicking it selects the car; its text contains name, type and price per day |
| `date-start` | rental start field (`input type="datetime-local"`) |
| `date-end` | rental end field (`input type="datetime-local"`) |
| `availability-status` | element saying whether the selected car is available for the selected dates |
| `book-car` | button that leads to the booking summary |
| `booking-summary` | container of the summary: car, dates, total cost |
| `edit-booking` | button or link in the summary that goes back to choosing car and dates |
| `payment-option` | each selectable payment method in the summary (repeated; radio, button or clickable option) |
| `confirm-payment` | button that pays and completes the booking |
| `booking-reference` | element of the confirmation screen that contains the booking code |
| `nav-bookings` | navigation item, visible from the home page, that leads to the list of bookings |
| `booking-row` | each booking in the list (repeated); its text contains code, car and dates |
